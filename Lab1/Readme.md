# Lab 01 – From a Single Neuron to a Layer

This lab introduces the basic concepts of deep learning and neural networks.

## Topics Covered

- Deep learning concepts and terminology
- Features, samples, batches, and labels
- Single neuron calculations
- Weights and biases
- Neural network layers
- NumPy matrix operations
- Array shapes
- Trainable parameter counting

## Assessment

The lab includes coding exercises and a final assessment covering forward passes, network shapes, predictions, and parameter counting.
